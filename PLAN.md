# H-ai-Safe – Phase 1 Project Plan

## Project Vision
H-ai-Safe is an educational web application focused on cybersecurity awareness and AI safety.

## Objective
Help users understand common cyber threats and learn practical ways to protect their digital information.

## Target Audience
Students, beginners, and individuals interested in cybersecurity.

## Webpage Map

| Page | URL | Description |
|---|---|---|
| Dashboard | / | Main introduction |
| Cyber Threats | /threats/ | Common cybersecurity threats |
| Safety Tips | /safety-tips/ | Practical security advice |
| About | /about/ | Project information |

## Navigation
All four pages are connected through a navigation menu.

## Technologies
- Python
- Django
- HTML
- CSS
- Mock data

## Phase 1 Scope
A working Django application with four frontend pages, navigation, and sample content. Advanced features are excluded.
